# NEON SURVIVOR // 霓虹幸存者

赛博朋克风格的「土豆兄弟 / Vampire Survivors」类网页游戏。
纯 HTML + CSS + 原生 JavaScript，**零依赖、零外部素材**——角色、敌人、地面、特效全部运行时用 Canvas 程序化绘制，音乐与音效由 WebAudio 实时合成。

## 背景设定

起初，AI 只是让生活更轻松的简单算法。后来它们学会了模仿人类，甚至让人喜欢上自己；再后来，出现了**武器化的 AI**——用来击穿敌方网络的军用技术。

黑客**拉奇·巴特莫斯**向公司的数据要塞下手，引发的却是彻底改变赛博空间的**数据崩溃**。AI 开始变异，成为致命威胁，**流窜 AI** 就此诞生。网络监察被迫筑起**黑墙**，唯一任务是拦住它们。

> 官方说没人去过黑墙另一边。非官方嘛……就看你愿意相信哪一个。

你是加装了战斗模块的**超级黑客**，在黑墙内侧清理渗漏的流窜 AI。中立 AI 会在波段间隙开放**黑市补给**——它不站队，只收信用点。

## 操作

| 平台 | 移动 | 冲刺 | 暂停 |
| --- | --- | --- | --- |
| 键盘 | `WASD` / 方向键 | `空格` / `Shift` | `Esc` |
| 鼠标 | 按住左键朝光标方向走 | `空格` / `Shift` | `Esc` |
| **手机 / 平板** | 左下**虚拟摇杆** | 右下 **⚡ DASH 按钮**（带冷却环） | 右上暂停键 |

其他：选择升级用 `1` `2` `3` 或直接点击，静音按 `M`。

**触屏说明**
- 控件只在**真移动设备**上出现（粗指针 + 无细指针，或移动端 UA）；笔记本触屏、桌面浏览器都不会显示。
- **竖屏直接用横屏界面**：整个舞台旋转 90° 铺满屏幕，和横屏时完全一样的 UI 与操作，不弹任何「请横屏」提示——微信等无法旋转屏幕的内置浏览器也能正常玩。
- 控件**叠加在游戏画面内**（不占屏幕外空间），所以移动场景可以撑满整屏。
- 摇杆是**灰白半透明**、104px；冲刺按钮 72px，**只有闪电图案**，无文字。
- 闪电图案与冲刺冷却联动：能量满时明亮饱满，消耗中逐渐变暗缩小，像能量在恢复；外圈白环同步收缩。
- 摇杆输出的是**像素级位移**（满推 56px），并会随竖屏旋转自动交换坐标轴，所以竖屏推「上」也是角色往屏幕上方走。
- 预览触屏控件可在网址加 `?force_touch=1`。

## 运行

双击 `index.html` 即可（无需服务器、无需联网），打开后进入**标题页**，可在三个角色和两种模式里自主选择。

网址参数（可选，用于跳过标题页直达战斗）：

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `auto` | `1` | 跳过标题页直接开战 |
| `class` | `runner` / `juggernaut` / `netrunner` | 选角色（需配合 `auto=1`） |
| `mode` | `standard` / `endless` | 10 波通关 / 无尽（需配合 `auto=1`） |

例如 `index.html?auto=1&class=juggernaut&mode=endless` 直接用重装机兵打无尽。

也可用本地服务器：

```powershell
python -m http.server 8000   # 然后打开 http://localhost:8000
```

## 玩法

- **自动射击**：武器自动索敌，你只负责走位与闪避。
- **两种运行模式**（开始界面可选）：
  | 模式 | 说明 |
  | --- | --- |
  | 标准行动 | **10 波通关**，清完第 10 波即撤离胜利，可一键转入无尽 |
  | 无尽深潜 | 没有终点，直到信号湮灭 |
- **每波 32 秒**，结束后进入黑市补给（终端会延迟约 1 秒启动，先让战场消散干净），再进下一波。
- **固定战场**：地图是一块 **2400×1500** 的有界区域，四周有发光约束墙与危险条纹；墙外是**黑白死区**（暗格网 + 扫描条），相机在贴墙时会向外多留 180px 余量，角色不会被顶到屏幕边缘。
- **波次修正**（赛博朋克命名，每波随机，HUD 顶部实时显示）：
  | 名称 | 效果 |
  | --- | --- |
  | 数据溢出 | 敌方进程疯狂复制，数量激增但单体更脆弱 |
  | 精英协议 | 敌人更少，但装备了强化外壳 |
  | 超频 | 敌方处理器过载，移动速度大幅提升 |
  | 装甲协议 | 敌人挂载额外护甲，伤害减免 |
  | 赏金悬赏 | 公司悬赏令生效，信用点掉落翻倍 |
- **每 5 波 Boss**：带进场介绍、招式预警；半血时展开**数据护盾**（短暂无敌，血条锁定金色，护罩拆解后才恢复输出）。
- **波次清场**：一波结束时场上敌人原地消散（扫描线拆解动画），地面拾取物一并清空，信用点**自动全额结算**。
- **生成白光**：新一波敌人出现前，落点会有一道白光闪过，可以预判威胁位置。
- **升级三选一**：升级武器 / 解锁新武器 / 安装义体模块（15 种被动）。
- **13 种武器**（含 2 把近战、2 种放置类），每把都有专属音效与获取时的详细档案卡（档案打开时战斗自动暂停）。
- **黑市回收**：可以把不要的武器卖回终端，返还信用点（等级越高卖得越多）。
- **拾取物**：经验宝石（四档）、信用点、修复包，以及三种稀有脉冲道具（清场炸弹 / 全屏吸经验 / 冰冻减速）。
- **经济**：信用点掉落为早期版本的 1/5，经验曲线同步放缓，升级节奏约每波 2–3 级。

## 三个角色

三个角色不是数值换皮，各有独有机制与起始武器：

| 角色 | 定位 | 独有机制 | 起始武器 |
| --- | --- | --- | --- |
| 突击者 | 机动压制 | 冲刺冷却 **-50%**、移速 +14%、攻速 +10% | 脉冲手炮（远程） |
| 重装机兵 | 近战硬碰 | 生命 +70、护甲 +4、**受击反伤 6**、速度 -14% | 热能太刀（近战） |
| 骇客 | 科技远程 | 经验 +30%、暴击 +10%、**额外投射物 +1** | 僚机无人机（远程） |

## 武器类型

| 类型 | 说明 | 代表 |
| --- | --- | --- |
| 远程投射 | 自动索敌的弹丸 / 激光 / 导弹 | 脉冲手炮、相位激光、蜂群导弹 |
| **近战斩击** | **仅在敌人进入范围时才出刀**（不会对空气挥砍浪费冷却）。热能太刀朝面向方向斩出两道交叉刀光，**交叉后继续向外延伸，等级越高延伸越远**（LV1 约 110px → LV8 约 248px）；作为代价**挥砍间隔较长**（LV1 0.99s → LV8 0.62s），单发高伤但每秒只能出一刀多；震荡拳套是重拳 + 命中点震荡波 | 热能太刀、震荡拳套 |
| **放置类** | 在脚下部署结构，**固定不随角色移动** | 哨戒无人机（自动炮台，会**吸引敌人火力**）、引力陷坑（减速力场） |
| 环绕 / 领域 | 绕身刀片、周期性冲击波 | 轨道旋刃、离子新星 |

## Boss 机制

每个 Boss 都会**组合两种招牌机制**，血量约为早期版本的 5 倍，出手频率也更高。

| 机制 | 表现 | 持有者 |
| --- | --- | --- |
| **镜像分裂** | 撕成两个半身，先拉开再朝你合拢绞杀，两半都能致死 | 监管者 |
| **光波晶格** | 多重、环形、交错、逐层外推的光弹幕，层间留有节奏缝隙 | 监管者 / 泰坦 |
| **相位闪现** | 短暂隐身（不可选中），随后贴到你身后，从身上向四周炸开**裂纹状闪电**，命中则**麻痹**（无法移动与攻击） | 泰坦 |
| **死亡自爆** | 倒下时不会安静：极短蓄力后炸出三层同心冲击波 | 泰坦 |

Boss 还共享：扇形弹幕、环形爆发、召唤、扫射激光、冲锋、迫击风暴、交叉激光、数据护盾。

**招式随机组合**：每个 Boss 实例在生成时都会从招池里随机抽取 3–4 招，且必定以自身招牌机制开场；
一轮打完会重新洗牌，所以同一局里的两次 Boss 战、或两次不同的通关，招式顺序都不一样。

## 敌人 AI

远程单位不会傻冲，而是维持各自的输出距离：

| 行为 | 说明 | 代表 |
| --- | --- | --- |
| 站桩狙击 | **完全不动**，远处放冷枪；蓄力时只有枪口能量球在膨胀，**没有瞄准线** | 切割者、哨戒炮台 |
| 冰冻射线 | 站桩，**冰蓝色**光束，命中后把玩家**冻结**，屏幕四周会结霜 | 霜冻者（第 8 波起） |
| 引力射线 | 站桩，**黑白交织**的光束，会把玩家**向发射源拉扯** | 牵引者（第 10 波起） |
| 保持射距 | 太远逼近、太近后退（后退比前进更快），进入射程后横向绕圈 | 枪手、狙击手、迫击机 |
| 环形攻击 | 贴近后原地放环形弹幕 | 重装兵 |
| 冲锋 | 蓄力画楔形，然后高速突刺 | 突刺兵 |
| 追击 | 直线压迫，贴身自爆或释放冲击波 | 巡逻机、自爆机、脉冲体 |
| **自爆冲锋** | 靠近后**原地生根蓄力**，蓄力期间**无敌**，引信无法打断；若在蓄力前被击杀，则**当场引爆** | 自爆蜂（小三角） |

扫描型激光会根据玩家所在方位决定**顺时针还是逆时针**扫过，所以站桩必被扫到，往反方向跑才是有效闪避。

| 类型 | 说明 | 代表敌人 |

| 环形爆发 | 以自身为中心射出全向弹幕 | 重装兵 |
| 狙击 | 长距离瞄准线 + 高速贯穿弹 | 狙击手 |
| 追踪弹 | 会自动拐弯的导弹 | 黄蜂 |
| 迫击炮 | 落点预警圈，延迟爆炸 | 迫击机 |
| 冲锋 | 蓄力画楔形，然后高速突刺 | 突刺兵 |
| **激光扫射** | 科技感引导线蓄力，然后横扫一道光束 | 切割者（第 6 波起） |
| **冰冻射线** | 命中后玩家被冻结，无法移动与攻击 | 霜冻者 |

以及招牌机制 **镜像分裂 / 光波晶格 / 相位闪现 / 死亡自爆**。

## 设计要点

- **两套完全不同的界面语言**：升级界面是青紫色「义体植入手术台」（竖版模块卡、等级刻度、扫描线），黑市是绿琥珀色「终端机」（等宽字体、编号货架、PURCHASE 指令）；两者都套了**全息投影**处理（扫描滑动、轻微闪烁、投影光锥）。
- **打击感**：命中顿帧、暴击缩放弹跳数字、方向性火花、分级屏幕震动、Boss 击杀慢动作 + RGB 色差。
- **画面**：降采样泛光后处理、漂浮尘埃氛围粒子、地面预警圈与瞄准线、扫描线暗角。
- **Boss 护盾**：金色六边形能量罩 + 轨道粒子 + 扫描弧，血条同步锁定金色并显示独立护盾计时条。
- **弹幕性能**：子弹的光晕/核心烘焙成按颜色缓存的 sprite，一颗子弹只做一次 `drawImage`；
  弹幕超过 50 / 90 发时自动降低光晕强度，避免「光污染」并稳住帧率
  （200 发弹幕实测 ≈ 0.08 ms/帧，约占 60fps 预算的 0.5%）。
- **音乐**：16 步进音序器，含贝斯、底鼓、军鼓、踩镲、琶音、铺底与主旋律；强度随战况动态变化，Boss 战切换为更快的调式。

## 文件结构

```
index.html          页面骨架 + HUD / 各界面 + 移动端控件
css/style.css       赛博朋克 UI（两套界面语言、扫描线、故障文字、移动端控件）
js/core.js          数学工具、输入（键盘/鼠标/触摸）、WebAudio 音效与音乐引擎
js/data.js          全部数值 + 程序化美术（角色/敌人/Boss/拾取物）
js/game.js          主循环、玩家、武器、敌人 AI、Boss 招式、碰撞、特效、渲染
js/ui.js            界面切换、义体植入、黑市终端、武器档案、HUD、舞台缩放
js/touch.js         移动端虚拟摇杆 + 冲刺按钮（自动识别触屏、竖屏换边）
js/main.js          启动
js/devtest.js       自动化测试钩子（仅 ?devtest 生效）
tools/              开发期验证脚本
```
